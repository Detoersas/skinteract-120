# Dead Signal — SK INTERACTIVE

An art-directed, static website for **Dead Signal**, a Russian roulette horror experience in early beta on Roblox.

## Art direction

The site is built around a bespoke cut-paper world: hundreds of small irregular paper fragments, angular face-like compositions, paper grain, offset cut edges, and hand-built treatments for the navigation, buttons, highlights, gallery, social links, and footer. The interface begins in grayscale, then gradually restores its red and yellow accents as the visitor scrolls down. The collage flecks stay strictly red, black, and white, while the provided game screenshots and video retain their original colors. The collage SVGs are stored locally as `paper-collage-world.svg` and `paper-collage-mobile.svg`.

The writing is intentionally direct and informal. The site only claims that Dead Signal is a Russian roulette experience in early beta; it does not invent additional game modes or lore.

## Run locally

Open `index.html` in a browser. No build step, framework, package install, or server is required.

## Publish

Upload the contents of this folder to GitHub Pages or another static website host. Keep the HTML, CSS, JavaScript, SVG, logo, screenshots, and MP4 in the same folder so the relative asset paths work.

## Included

- Responsive navigation for desktop and mobile
- Original cut-paper collage artwork recolored to red, black, and white
- Scroll-driven grayscale-to-red/yellow theme transition
- Updated Bricolage Grotesque and Space Mono typography
